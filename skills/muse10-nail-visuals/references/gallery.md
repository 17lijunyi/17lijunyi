# 图库交互与预览打包

先读取当前可用的 `visualize` 技能。这里的模板是对话预览组件，不是在线网站，也不提供支付、账户或真实AI接口。

## 状态规则

每件作品维护当前图片索引和是否手动翻页，互不影响。图片顺序通常为：0十片陈列、1双手佩戴、2局部特写。

| 操作 | 结果 |
|---|---|
| 初始 | 显示0 |
| 鼠标进入，尚未手动翻页 | 临时显示1 |
| 鼠标离开，尚未手动翻页 | 恢复0 |
| 前后箭头/横向滑动/键盘左右键 | 改变索引并记为手动操作 |
| 手动操作后鼠标离开 | 保持当前索引 |
| 点击作品图或名称 | 打开同一套的大图浏览 |
| 返回/Escape | 返回作品列表 |

采用约280ms的水平位移过渡，尊重减少动态效果设置。细箭头在图片两侧垂直居中，无大圆底色。无悬停设备保留可见箭头、触摸区域和纵向滚动。滑动后不得误触点击打开。

过去的视频证明的是悬停与箭头横向换图；手机滑动和大图浏览是本方法的预览交互要求，不能声称它们也出现在该段视频中。

## 使用打包脚本

`scripts/build_preview.py` 只把已生成的本地图像嵌入图库，不生成或重绘图像、不访问网络、不修改网站。脚本使用Python标准库；接受PNG、JPEG、WebP和GIF。静态输入通常优先JPEG或WebP以控制体积。

准备一个UTF-8 JSON清单，所有相对图片路径相对清单所在目录解析：

```json
{
  "brand": "Muse10",
  "title": "作品展示",
  "products": [
    {
      "name": "你的定制作品",
      "note": "10片 · AI效果预览",
      "images": ["master.jpg", "wear.jpg", "detail.jpg"],
      "labels": ["十片陈列", "双手佩戴", "局部特写"]
    }
  ]
}
```

运行时将下列技能路径替换为实际安装位置：

```bash
python3 /absolute/skill/scripts/build_preview.py \
  --manifest /absolute/work/gallery.json \
  --output /absolute/thread-visualizations/nail-gallery.html
```

- 输出必须是任务自己的持久文件，不能指向网站源码；脚本不覆盖已有输出，改用新文件名。
- 一套作品显示一个卡片；多套作品按三列排布。不要把三张视角图拆成三件商品。
- 输出严格小于1MB。超限时先另存适合预览的压缩副本，保留高清原图，再运行脚本；不要发布图片或改为不被允许的远端资源来绕开限制。
- JSON中的商品名、标签和品牌按文本处理，不能变成执行代码。不要在清单中接受远端URL、脚本或系统命令。
- 打包成功后按当前 `visualize` 技能交付；保存的是HTML片段，不要直接宣称可在微信公开访问。用户另行要求上线时才走相应网站发布流程。
- `assets/examples/gallery.json` 可用于打包自检，只包含本技能的花园款示例。不要把它当成新用户的作品。

## 检查重点

确认本地图片都已嵌入、默认图正确、悬停恢复和手动保留行为独立、箭头确实水平切换、触摸不会阻断页面纵向滚动、大图可以返回。若需要浏览器检查，使用可用的浏览器技能和可视化技能的预览包装方式；不能因工具检查受阻而声称已经验证。
