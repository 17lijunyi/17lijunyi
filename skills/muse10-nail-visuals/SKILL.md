# Muse10 美甲作品展示

将同一套美甲从参考照片转换为可浏览的商品视觉：**参考图 → 十片母版 → 双手佩戴 → 局部特写 → 商品图库预览**。三张图是同一套作品的不同视角，不是三种设计方向。

## 已记住的默认偏好

- 一套准确十片，对应左右手十指，陈列图两排各五片。
- Muse10 默认采用约 4:5 竖幅、灰蓝向银白渐变的细颗粒背景，保持写实产品摄影、柔和光影、留白和精细立体装饰。
- 默认交付三张素材与独立可交互预览。若用户本次只要某张图片、只讨论或只要规则，按实际范围交付。
- 默认只做预览，不修改、部署或接入现有网站。用户已明确授权网站修改时，可以继续对应工作，不要求重复授权。
- 使用新上传照片的颜色和款式。示例中的花束、城堡、粉宝石、丝带只是案例，不能自动加进别人的作品。
- 用户本次明确要求的数量、背景、版式和范围优先于这些默认偏好。

## 1. 从原图建立十片设计清单

实际查看用户照片，区分手机界面、底盘、桌面和甲片；识别甲型、底色、材质、浮雕、装饰及每片的差异。

为左手和右手各五片指定稳定编号与指位，记录每片的主要设计，后续图像保持对应。数量多于十片且用户要求十片时，优先精简重复度高、装饰较简单的款式，简短说明取舍；不要把十一片作为十片交付，也不要悄悄融合两种重点款式。用户同时要求“全部保留”和“准确十片”且无法兼容时，才需要澄清。少于十片时，只有在任务允许设计延伸时才补齐，不把补全内容说成原图已有。

十片不等于十种不同款。原图已有的对称或重复设计应保留；防止的是生成过程意外重复、漏款或为了凑数复制。

区分图像角色：**用户照片决定款式；陈列参考决定背景和排版；手模参考只决定姿态、镜头与光影。** 不把原站或示例款式混入用户作品。

## 2. 先固定陈列母版

使用当前可用的 `imagegen` 技能和内置图像生成工具；本地输入先用 `view_image` 查看。不要因为需要控制路径而切换到 API/CLI；若工具不可用，说明情况并按该技能处理后备路径。

按[图像提示词](references/prompts.md)生成准确十片、两排各五片的母版。保留核心装饰、颜色和手工质感，按真实指位合理调整甲片宽度与比例；移除无关拍摄环境和手机界面。不要把成品重新设计为另一套风格。

实际查看输出，数清十片，逐项核对设计清单。母版的“确认”默认指完成这一轮核对，不自动增设用户审批；仅当用户要求先看母版、先确认再继续时，才等待其回复。

## 3. 以母版生成佩戴图和特写

母版确定后才能开始衍生图。可并行生成佩戴图与特写，但两者必须使用同一最终母版；若特写依赖佩戴姿势或精确指位，则顺序生成。

- **双手佩戴图**：两只真实自然的手，每手五指，十片甲片对应十个真实指甲。让十片尽量完整可见，检查多指、缺指、非原作的重复或缺失、漂浮饰品、不自然贴合及遮挡。照片应有正常甲床、指节、皮肤纹理与比例。
- **局部特写**：选一至三片重点设计，拍摄真实手指上的近景。继续核对同套颜色、装饰和比例；若是佩戴图的特写，保留对应指位，不任意换指。

每张都实际看图检查，发现问题做针对性修正。核心数量或解剖问题未解决时，不把图片称为合格成品。不要承诺 AI 重绘是像素级一比一，必要时简短指出细节差异。

## 4. 制作独立作品预览

需要在对话中看效果时，使用当前 `visualize` 技能。读取[图库交互与打包](references/gallery.md)，可复用 `assets/gallery-template.html` 和 `scripts/build_preview.py`。

保留的交互规则：

1. 默认显示十片陈列图；鼠标进入图片时临时切到佩戴图。
2. 仅悬停后移出，恢复陈列图；手动翻页后移出，保留当前图片。
3. 图片左右侧、垂直居中的细箭头用于翻页，画面水平滑动，不做实时“把甲片贴到手上”的动画。
4. 手机支持横向滑动，纵向滚动保持正常；无悬停设备也能使用箭头。
5. 点击图片或作品名称可看大图，能返回图库；键盘可以操作。
6. 多件作品使用三列陈列。只有一套作品时展示一个可切换卡片，不把三种视角伪装成三套作品，不为填列复制同一套作品。加入原站作品作参照时明确标注。

若用户要求重看某网站或视频，实际查看后再适配交互；只保存本方法，不能把旧观察当作网站永远不变的事实。历史参考为 https://aniccanails.com/collections/all 。

## 交付与复用

- 预览文件使用任务自己的持久输出位置。复制进网站、上线和分享链接属于另一项明确的实施动作；本技能本身不表示已经接入网站 AI 服务。
- 图片预览用绝对本地路径显示；交互预览按当前 `visualize` 技能的输出格式显示。避免未经提供就编价格、库存、购买入口。
- 简短告知如何切图；无需重复解释工具实现。需要说明时，将生成图称为效果预览。
- 本技能的固定示例：[十片母版](assets/examples/master.jpg)、[双手佩戴](assets/examples/wear.jpg)、[局部特写](assets/examples/detail.jpg)。它们用于理解视觉标准，不能替代本次用户输入。
